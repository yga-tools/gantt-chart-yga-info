Gantt Chart by YGA — Política de Privacidad

Última actualización: 17 de octubre de 2026

1. Introducción

Gantt Chart by YGA («el Objeto visual») es un objeto visual personalizado para Microsoft Power BI desarrollado por Yolanda García Antón. Esta política explica cómo trata los datos el Objeto visual.

2. Recopilación de datos

El Objeto visual no recopila, almacena ni transmite ningún dato personal ni dato del informe al desarrollador ni a terceros. Todos los datos que conecta al Objeto visual se procesan de forma local, dentro de su entorno de Power BI (Power BI Desktop o el servicio Power BI), en su propio dispositivo, con el único fin de representar el gráfico.

3. Acceso a la red

El Objeto visual no realiza ninguna conexión externa de red. No utiliza acceso web ni servicios externos, y no envía ningún dato fuera de Power BI.

4. Almacenamiento local

El Objeto visual utiliza el almacenamiento local del navegador únicamente para recordar preferencias de interfaz (como los grupos colapsados y el ancho de las columnas) en su propio dispositivo. Esta información nunca sale de su dispositivo y no es accesible para el desarrollador.

5. Terceros

El Objeto visual no comparte ningún dato con terceros.

6. Cambios en esta política

Esta política puede actualizarse con el tiempo. La versión más reciente estará siempre disponible en esta página.

7. Contacto

Para cualquier consulta sobre esta política, contacte con: soporte@yoyocloud.es

1. Overview

Gantt Chart by YGA ("the Visual") is a custom visual for Microsoft Power BI developed by Yolanda García Antón. This policy explains how the Visual handles data.

2. Data collection

The Visual does not collect, store, or transmit any personal data or report data to the developer or to any third party. All data you connect to the Visual is processed locally, within your Power BI environment (Power BI Desktop or the Power BI Service), on your own device, for the sole purpose of rendering the chart.

3. Network access

The Visual does not make any external network connections. It does not use web access or external services, and it does not send any data outside Power BI.

4. Local storage

The Visual uses your browser's local storage only to remember interface preferences (such as collapsed groups and column widths) on your own device. This information never leaves your device and is not accessible to the developer.

5. Third parties

The Visual does not share any data with third parties.

6. Changes to this policy

This policy may be updated over time. The latest version will always be available on this page.
